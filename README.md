# VisualVault – Interactive Image Gallery 📸

A modern, high-performance, and responsive Image Gallery web application built as part of my **Frontend Development Internship** at **CodeAlpha**.

This project provides an intuitive visual interface for exploring high-resolution photography categorized across Cities, Beaches, Cars, Nature, Animals, and Architecture. It features dynamic category filtering, responsive CSS grid layouts, and a full-screen Lightbox modal with keyboard accessibility.

---

## ✨ Key Features

* **Dynamic Category Filtering:** Instantly filter images by category (Cities, Beaches, Cars, Nature, Animals, Architecture) without reloading the page.
* **Full-Screen Lightbox Modal:** View high-resolution images in a focused lightbox mode with next/previous navigation controls.
* **Keyboard Accessibility:** Navigate through lightbox images using `Left Arrow` / `Right Arrow` keys and close using the `Escape` key.
* **Modern UI & Smooth Animations:** Designed with custom hover overlay effects, smooth gradient text, and CSS card elevation.
* **Fully Responsive:** Optimized layout using CSS Grid and Flexbox for seamless browsing across desktop, tablet, and mobile screens.

---

## 🛠️ Tech Stack

* **HTML5:** Semantic markup structure.
* **CSS3:** Custom styles, CSS Grid, Flexbox, media queries, and smooth transition animations.
* **JavaScript (ES6):** Dynamic rendering, array filtering, event handling, and DOM manipulation.
* **FontAwesome:** Scalable vector icons for lightbox UI navigation.

---

## 🚀 How to Run Locally

1. Clone or download this repository.
2. Open the project folder in VS Code or any text editor.
3. Open `index.html` directly in your browser or run via VS Code **Live Server**.
